 [ キーボード操作 ]

//============================
// 移動操作
//============================
W/A/S/Dキー

//============================
// 吹き飛ばし操作
//============================
ENTERキー長押し

//============================
// ブロワーの強さ変更
//============================
Q,Eキーで段階的に変化

//============================
// 画面遷移
//============================
Enterキー遷移

//============================
// ポーズ
//============================
Pキー , 決定はEnterキー、選択入力は W/S ↑/↓

 [ コントローラー操作 ]

//============================
// 移動操作
//============================
十字キー or 左スティック

//============================
// 吹き飛ばし操作
//============================
Xボタン長押し

//============================
// ブロワーの強さ変更
//============================
L1,L2,R1,R2ボタンで変更

//============================
// 画面遷移
//============================
Aボタン もしくわ startボタン

//============================
// ポーズ
//============================
startボタン 選択は十字キー 決定はAボタン
